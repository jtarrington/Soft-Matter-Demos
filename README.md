# Soft Matter Demos

Interactive simulations for soft matter physics built for STEM outreach.
Click the button below to explore some demos.
Runs best on PCs.

[![Launch Demos](https://img.shields.io/badge/Launch%20Demos-→-blue?style=for-the-badge)](https://jtarrington.github.io/Soft-Matter-Demos/src/)

---

## Demos

| Demo | Description |
|------|-------------|
| [Boids](https://jtarrington.github.io/Soft-Matter-Demos/src/boids.html) | Flocking simulation based on simple rules. The mouse acts like a predator that the flock tries to avoid! |
| [Active Brownian Particles](https://jtarrington.github.io/Soft-Matter-Demos/src/abp.html) | Simple box containing active Brownian particles. These self-propelled particles phase-separate into locally dense regions, like a traffic jam!|

## Running Locally

```bash
git clone https://github.com/jtarrington/Soft-Matter-Demos.git
cd Soft-Matter-Demos
open src/index.html
```
