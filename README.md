# Soft Matter Demos

Interactive simulations for soft matter physics — built for STEM outreach and sandbox exploration.

[![Launch Demos](https://img.shields.io/badge/Launch%20Demos-→-blue?style=for-the-badge)](https://jtarrington.github.io/Soft-Matter-Demos/src/)

---

## About

A collection of browser-based simulations exploring soft matter concepts such as fluid dynamics and emergent collective behavior. No installation required — runs entirely in the browser.

## Demos

| Demo | Description |
|------|-------------|
| Boids | Flocking simulation based on separation, alignment, and cohesion rules |

## Running Locally

```bash
git clone https://github.com/jtarrington/Soft-Matter-Demos.git
cd Soft-Matter-Demos
open src/index.html
```

## Built With

- [Paper.js](http://paperjs.org/) — vector graphics & animation
